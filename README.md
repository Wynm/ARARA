# ARARA | دفتر الطالب

استوديو صغير يصنع درسًا عربيًا رأسيًا (720×1280، MP4) على المعالج: سؤال، فكرة الحل، حساب، ثم تمرين. البداية بثلاثة أنواع قابلة للتحقق: الخصم عند الشراء، متوسط السرعة، وحساب وقت المراجعة. يغيّر الأرقام ويحسب الإجابات، ويكتب العنوان والوصف والوسوم في `metadata.json`. لا يقتبس مقاطع الآخرين ولا يولّد فتاوى. المولّد الحسابي ليس نموذجًا لغويًا؛ الجزء المعتمد على الذكاء الاصطناعي هو التعليق الصوتي الاختياري.

**شاهد [درسًا مُنتجًا فعليًا](examples/lesson.mp4)**. المثال المرفق وتشغيل `studio.py` دون `--voice` صامتان ويعمل التوليد المحلي دون اتصال بعد التثبيت. في دفتر Colab، التعليق الصوتي مفعّل افتراضيًا. الخطوط والرسوم تُرسم محليًا. لا موسيقى في أي وضع. الصوت السحابي وصور Pexels اختياريان، وفشلهما يوقف المهمة قبل النشر.

## على Windows 10

1. فك حزمة المشروع في مجلد مثل `C:\ARARA` وافتح فيه PowerShell. استخدم Python 3.10 أو أحدث (64 بت). لا تحتاج CUDA أو Docker أو خادمًا أو OpenAI. حزمة `imageio-ffmpeg` توفّر FFmpeg على Windows x64.
2. شغّل:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\python -m pip install -r requirements.txt
   .\.venv\Scripts\python studio.py --seed 42
   ```

3. افتح المسار المطبوع داخل `output`؛ ستجد `lesson.mp4` والوصف. احذف `--seed 42` للتنويع. إذا تعذّر تحميل الخط، اضبط `$env:ARABIC_FONT='C:\Windows\Fonts\arial.ttf'`. على Linux استخدم خط DejaVu Sans.
4. للتعليق المغربي العربي (يتطلب اتصالًا بخدمة Edge، بلا مفتاح) أو النشر، ثبّت الإضافات. للحصول على صورة خلفية صحراوية بدل الخلفية المرسومة، ضع **مفتاح Pexels جديدًا** في متغير البيئة `PEXELS_API_KEY` محليًا، ثم:

   ```powershell
   .\.venv\Scripts\python -m pip install -r requirements-extra.txt
   .\.venv\Scripts\python studio.py --voice --pexels
   ```

   يمكن استخدام أي خيار وحده. يُرسل نص الدرس لخدمة الصوت عند اختيارها. مصدر الصورة ورابط المصوّر يُضافان للوصف. راجع ترخيص الصورة وشروط استخدام الصوت التجاري قبل تحقيق الدخل. إذا تعطلت الخدمة، احذف الخيار المقابل. لا حاجة إلى Unsplash أو خدمات مدفوعة.

## Google Colab — تجربة كاملة بلا Docker

[افتح الدفتر مباشرة في Colab](https://colab.research.google.com/github/Wynm/ARARA/blob/main/ARARA_Colab.ipynb) أو انقر `Open-Colab.cmd` في Windows. لا تحتاج رفع الحزمة. اختر **CPU** ثم **Runtime → Run all**. قد يطلب Google تسجيل الدخول وموافقتك على تشغيل دفتر من GitHub. المعاينة الافتراضية تنتج درسًا بلا مفاتيح. لتغيير الخيارات وحفظها للجلسات المقبلة أنشئ نسخة خاصة من الدفتر في Drive.

- `count` عدد الدروس في دفعة اليوم (1–5). `voice` مفعّل افتراضيًا للتعليق الصوتي العربي بلا موسيقى. إذا كنت تستخدم نسخة قديمة صامتة، فعّل `voice` وأعد تشغيل **كل الخلايا** كي تُثبّت إضافة الصوت. يُحفظ الفيديو الناطق في دفعة `voice1` منفصلة؛ لن يتغيّر ملف `voice0` السابق. تفعيل `pexels` يحتاج `PEXELS_API_KEY` جديدًا في **Secrets** (رمز المفتاح الجانبي مع تفعيل Notebook access).
- **YouTube:** نفّذ التفويض المحلي الموضّح أدناه مرة أولى. انسخ **محتوى ملف** `secrets/youtube.token.json` إلى سرّ خاص في Colab باسم `YOUTUBE_TOKEN_JSON` (ليس ملف إعداد العميل). لا تضعه في الدفتر أو المشروع. اختر `youtube` وحدد `visibility`. إذا انتهى التفويض أو ألغي، أعده وحدّث السرّ.
- **Facebook:** أضف `FB_PAGE_ID` و`FB_PAGE_TOKEN` إلى Secrets واختر `facebook`. اختيار `both` يتطلب إعداد المنصتين؛ رفع Facebook علني بصرف النظر عن خيار YouTube.
- `save_to_drive` يحفظ الفيديو والوصف وإيصال كل منصة تحت `MyDrive/ARARA`، دون حفظ أسرار النشر هناك. إن تركته معطّلًا نزّل الملفات من `/content/arara-output` في لوحة Files قبل انتهاء الجلسة. **لا تستخدم التخزين المؤقت إذا كنت تريد استئناف النشر بعد انقطاع الجلسة.** عند إعادة التشغيل بنفس خيارات الصوت والصورة في اليوم نفسه (UTC) يستأنف الدفتر نفس الدفعة، ويتجاوز كل رفع مؤكّد. لا يحوّل فيديو خاصًا إلى عام بمجرد إعادة تشغيله. بعد تغيّر اليوم، استكمل الدرس القديم بأمر `publish.py upload` بدل توقع استئنافه تلقائيًا.
- لا يمكن ضمان تشغيل Colab المجاني دائمًا أو تجاوز حد الجلسة. لا يوجد نقر اصطناعي أو حيلة إبقاء اتصال. للأتمتة اليومية التي لا تعتمد على جلسة المتصفح استخدم مجدول Windows أدناه.

## ربط النشر مرة واحدة على الحاسوب

لا تستخدم كلمة مرور أو مفتاح قراءة YouTube للرفع. لا يحتاج المشروع بيانات دفع. خزّن الملفات في `secrets/` المستثنى من Git. لا تشارك هذا المجلد أو تضفه إلى حزمة Colab.

**YouTube:** فعّل YouTube Data API v3 في مشروع Google، واضبط شاشة الموافقة وأضف حساب القناة كمستخدم اختبار إذا كان التطبيق في وضع الاختبار. أنشئ OAuth Client من نوع **Desktop app** ونزّل JSON إلى `secrets/client_secret.json`. نفّذ الأمر الأول على الحاسوب حيث يمكن فتح المتصفح، واختر القناة ووافق على صلاحية الرفع. بعد ذلك يقرأ البرنامج التفويض المخزّن ويجدّده ما دام صالحًا.

```powershell
.\.venv\Scripts\python publish.py authorize-youtube
.\.venv\Scripts\python studio.py --publish youtube
```

الرفع **خاص** افتراضيًا. بعد مشاهدة النتيجة اضبط `$env:YOUTUBE_VISIBILITY='public'` إذا أردت طلب النشر العام. قد يفرض YouTube الخصوصية على مشاريع API غير المدققة؛ الرفع لا يعني أن الفيديو أصبح عامًا. قد تتطلب تطبيقات الاختبار إعادة التفويض. راقب حصة الرفع في لوحة المشروع.

**Facebook:** استخدم **رمز صفحة** جديدًا وليس رمز مستخدم، مع صلاحية `pages_manage_posts` والصلاحيات التابعة التي تتطلبها Meta ومهمة إنشاء المحتوى على الصفحة. لا تمنح صلاحيات الإعلانات أو المال. اضبط `FB_PAGE_ID` و`FB_PAGE_TOKEN` في متغيرات بيئة المستخدم. أعد فتح PowerShell. الأمر `studio.py --publish facebook` يرفع فيديو عاديًا إلى الصفحة فور الإنتاج؛ **ليس مسودة ولا يستخدم واجهة Reels**. راجع شروط الصفحة وحالة التطبيق لدى Meta إذا رُفض الإذن. للنشر على المنصتين: `studio.py --publish youtube facebook`.

**استكمال رفع درس موجود:** `python publish.py upload output/JOB_ID youtube` (استبدل المسار بما طُبع واستعمل Python من البيئة). إيصال مستقل لكل منصة يمنع إعادة الرفع من **مجلد الدرس نفسه**. إذا ظهر `pending` فقد انقطع الاتصال قبل معرفة النتيجة. تحقّق من القناة/الصفحة ثم احذف ذلك الإيصال فقط إذا تأكدت من عدم الرفع. لا تُعِد أمر التوليد لاستكمال رفع سابق. كل تشغيل جديد ينتج مجلدًا جديدًا؛ لا ضمان لعدم تكرار المسائل بين التشغيلات.

## تشغيل يومي دون خادم

بعد تجربة أمر النشر يدويًا، تستطيع تسجيل مهمة يومية مرة واحدة من PowerShell (الساعة محلية):

```powershell
.\Schedule-Studio.ps1 -Target youtube -At 18:00
```

يدعم `-Target facebook` أو `-Target both` و`-Voice`. يعمل عند تسجيل دخول مستخدم Windows وعلى جهاز مشغّل. عطّل المهمة بأمر `Disable-ScheduledTask -TaskName 'ARARA Studio'`. إذا منعت سياسة الجهاز السكربت فلا حاجة لتغييرها؛ للإعداد اليدوي افتح **Task Scheduler → Create Task** على Windows. اختر حساب المستخدم نفسه، ومشغّلًا يوميًا. في **Action → Start a program** عيّن:

- Program: `C:\ARARA\.venv\Scripts\python.exe`
- Arguments: `studio.py --voice --publish youtube` (أضف `facebook` فقط إذا أردت نشرًا عامًا على الصفحة).
- Start in: `C:\ARARA`

استبدل المسار بموقع التثبيت. احفظ متغيرات البيئة المطلوبة في إعدادات المستخدم وليس في وسائط المهمة. فعّل «Run task as soon as possible after a scheduled start is missed» واختر منع تداخل النسخ. يجب أن يكون الجهاز قيد التشغيل، والإنترنت متاحًا للرفع. افحص الإيصالات بعد أول مهمة واحذف الفيديوهات القديمة عند الحاجة لتوفير المساحة. لتعطيل الأتمتة عطّل المهمة من المجدول.

### إذا توقفت خلية الإنتاج في Colab

`CalledProcessError` وحده يعني أن `studio.py` توقف، ولا يحدد السبب. إذا كان الأمر المعروض لا يحتوي على `--voice` أو `--pexels` فهذان الخياران ليسا سبب هذا التوقف، ولم يصل الدرس إلى خطوة الرفع. يعرض الدفتر المحدّث نص خطأ المولّد في الخلية نفسها. في نسخة قديمة، نفّذ هذه الخلية بعد الخطأ وفي الجلسة نفسها لعزل الإنتاج عن النشر (لا تحتاج إلى أي سر):

```python
with tempfile.TemporaryDirectory() as work:
    r = subprocess.run([sys.executable, 'studio.py', '--output', work, '--seed', '202611201'],
                       cwd=root, capture_output=True, text=True)
    print(r.stderr if r.returncode else 'نجح اختبار الإنتاج')
```

إذا ظهر `ModuleNotFoundError` فأعد تشغيل خلية تثبيت الاعتماديات وتحقق أنها انتهت بلا خطأ. إذا ظهر `Set ARABIC_FONT` فاستخدم خط DejaVu المرفق مع Matplotlib كما يفعل الدفتر المحدّث. إذا ذكر الخطأ FFmpeg، اقرأ رسالة المشفّر قبل السطر الأخير من التتبّع. لا تحذف مجلد الدفعة أو إيصالات الرفع لتشخيص فشل الإنتاج.
